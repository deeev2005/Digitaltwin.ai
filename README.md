# DigitalTwin.ai

**DigitalTwin.ai** is an interactive prototype that demonstrates how data from a physical manufacturing line can be transformed into a real-time **digital twin and industrial intelligence system**.

The prototype visualizes the flow:

**Production Line → IoT Signals → Digital Twin → AI Intelligence → Predictive Actions → Operator Decisions**

## Features

* **Digital Twin**
  Interactive visualization of vehicle assemblies, production stations, and sensor activity.

* **Industrial Intelligence**
  Demonstrates anomaly detection, root cause analysis, and predictive maintenance insights.

* **Operations & Traceability**
  Track individual units as they move through different stages of production.

* **Simulation & Validation**
  Simulate sensor changes, signal drift, and operational conditions to demonstrate how the system responds.

## Getting Started

### Prerequisites

Make sure you have:

* Node.js 20+
* pnpm 9+

If you don't have pnpm installed:

```bash
npm install -g pnpm
```

### Installation

Clone the repository:

```bash
git clone <repository-url>
cd digitaltwin-ai
```

Install dependencies:

```bash
pnpm install
```

### Run Locally

Start the development server:

```bash
pnpm dev
```

Open the local URL shown in your terminal.

## About the Prototype

DigitalTwin.ai is an **interactive prototype** created to demonstrate the architecture and user experience of an industrial digital twin platform.

It shows how physical manufacturing operations can be connected with real-time data, digital representations, AI-driven intelligence, and predictive operational insights.
